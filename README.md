## 📌 Project Overview

The **Students Social Media Addiction Dashboard** is an interactive Power BI data analytics project designed to analyze student social media usage and explore its relationship with **academic performance, mental health, sleep, lifestyle, relationships, and conflicts**.

The project transforms student-level data into an interactive dashboard that allows users to explore patterns across **age, gender, academic level, country, relationship status, and social media platform**.

The dashboard also includes **interactive storytelling, slicers, navigation, and drill-through functionality** for detailed student-level analysis.
---
## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze social media usage among students
* Identify usage patterns across different age groups
* Compare social media usage across academic levels
* Analyze potential academic performance impact
* Explore the relationship between addiction score and mental health
* Analyze sleep patterns in relation to social media usage
* Understand relationship status and conflict levels
* Identify the most-used social media platforms
* Provide student-level insights through drill-through analysis
* Build an interactive and user-friendly Power BI dashboard
---
## 📊 Dashboard Overview

The Power BI report consists of **six major analytical sections**:

### 1️⃣ Executive Overview

The Executive Overview provides a high-level summary of the student dataset.

### Key KPIs

| KPI                 |          Value |
| ------------------- | -------------: |
| Total Students      |        **705** |
| Average Usage       |    **5 Hours** |
| Academic Impact     |        **64%** |
| Average Sleep Hours | **6.87 Hours** |

The page also includes:

* Gender Distribution
* Average Usage Hours by Age
* Addicted Score vs Academic Level
* Interactive navigation to other dashboard pages
---
### 2️⃣ Mental Health & Lifestyle

This page focuses on the relationship between social media usage, addiction, sleep, and mental health.

### Analysis Includes

* Addicted Score vs Mental Health Score
* Sleep Hours vs Usage
* Average Sleep Hours by Age
* Gender-based filtering
* Interactive slicer for Gender

This section helps explore patterns between **social media behavior, sleep, and mental health indicators**.
---
### 3️⃣ Academic Impact

This section analyzes the potential relationship between social media usage and academic performance.

### Visualizations Include

* Average Daily Usage Hours by Academic Level
* Academic Performance Impact by Platform
* Age Range Slicer
* Platform-level comparison

The dashboard allows users to investigate how academic impact varies across different social media platforms and academic levels.
---
### 4️⃣ Relationships & Conflicts

This page analyzes relationships and conflicts among students.

### Visualizations Include

* Conflict Level by Relationship Status
* Relationship Status Distribution
* Country Slicer
* Academic Level Slicer

Relationship categories analyzed include:

* Single
* In Relationship
* Complicated
---
### 5️⃣ Interactive Story View

The Interactive Story View uses **Power BI bookmarks** to provide two different analytical perspectives.

### 👤 Gender View

Includes:

* Average Daily Usage Hours by Gender
* Most Used Platform by Gender

### 🎓 Academic View

Includes:

* Average Daily Usage Hours by Academic Level
* Most Used Platform by Academic Level

Users can switch between the **Gender View** and **Academic View** using interactive controls.
---
### 6️⃣ Student Profile

The Student Profile page uses **Power BI Drill-through** functionality to provide detailed information about an individual student.

### Student-Level Information

* Student ID
* Gender
* Age
* Country
* Academic Level
* Sleep Hours
* Usage Hours
* Addicted Score
* Most Used Platform
* Conflicts
* Mental Health Rating

This allows users to move from overall dashboard insights to a detailed individual student profile.

# 🚀 How to Use This Project

### Step 1: Clone the Repository
```bash
git clone [GitHub Repository Link]
```

### Step 2: Open the Power BI File

Navigate to:

```text
PowerBI/
```

Open:

```text
Students_Social_Media_Addiction.pbix
```
using **Power BI Desktop**.

### Step 3: Check the Data Source

If Power BI asks for the dataset location:

1. Open **Transform Data**
2. Select **Data Source Settings**
3. Update the dataset path if required
4. Apply the changes

### Step 4: Refresh the Dashboard

Click:

**Home → Refresh**

The dashboard will update using the connected dataset.
